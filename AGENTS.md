# Website logo rules

- The only approved logo is the owner's `D:\SW\logo321.svg`, stored in this repository as `public/images/logo321.svg`.
- All displayed logos, favicons, Apple touch icons, social metadata logos and structured-data logos must use this artwork or its generated size/format derivatives.
- Run `npm run favicons:generate` to regenerate these assets from the approved SVG.
- Do not recreate or restore the former simplified `brand-mark.svg` or introduce another logo design.
- Keep favicon URLs stable. A deployment does not prove Google Search or Search Console has refreshed its cached icon.
